# Zhang-ling0 — Developer Dashboard

A responsive dark developer portfolio built with vanilla HTML, CSS, and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. For best results, use VS Code's Live Server extension.
3. The GitHub profile stats use the public GitHub API and require an internet connection.
4. The contribution heatmap preview is illustrative, not live contribution data. The contribution snake uses the existing `Zhang-ling0` workflow output URL.

## Publish with GitHub Pages
1. Create a repository named `Zhang-ling0.github.io` under your GitHub account.
2. Upload `index.html`, the `assets/` folder, and this README to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub Pages finishes publishing, open `https://Zhang-ling0.github.io`.

If you prefer to keep the website in a repository with another name, you can enable Pages in that repository; the URL will then include the repository name.
